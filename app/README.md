# JAKAWI Launch Engine

Aplicación Laravel 13, PHP 8.4, Inertia 3, React 19, TypeScript, Tailwind CSS 4 y Vite.

La portada es la única funcionalidad de producto implementada. No incluye registro, referidos ni pagos.

Consultar [el README de infraestructura](../README.md) para instalación, configuración, arranque y validación local. La configuración real se genera en `/srv/sites/jakawi.club/secrets/app.env` y no se almacena en este árbol.
